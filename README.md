# Le machine learning en pratique

## 1. Outils de base

* python, notebook
    * Installation du système
* numpy, matplotlib (+pandas)
    * Travail sur des matrices (et affichage)
* Algorithme de machine-learning *à la main*
    * Travail comme en 2000 :)
    * Compréhension en profondeur des mécanismes (bayesien naïf, gradient, ...)
    * Cette partie est très limitée ici: on peut la décliner sur les arbres, les SVM, le gradient-boosting, ... Toutes les techniques de base du machine learning.

## 2. Outils de ML

* Présentation des outils disponibles
    * scikit-learn
    * Une boite à outils fantastique, en perpetuelle extension
* Travail sur les protocoles de machine-learning
    * Comment vendre un modèle qui ne soit pas proprement évalué?
    * Comment réaliser cette évaluation en machine-learning?
* Intégrer les connaissances des experts & les trucs et astuces de l'analyse de données
    * Feature engineering
    * Optimiser les architectures
* Visualisation
    * Exposer ses travaux
    * Comprendre les erreurs et entrer dans une logique d'amélioration des modèles
* Extension vers l'apprentissage non supervisé
